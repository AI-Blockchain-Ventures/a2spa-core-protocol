# Specification Artifacts

This directory contains A2SPA Core Protocol specification artifacts.

## Current Text

- `A2SPA_Core_Protocol_Specification_v0.9.3.md` is the current review draft, aligned with A2SPA `2.4.2` (protocol `v1.0`, HTTP API `/v1`).

## Historical Note

`v0.9.2` (September 3, 2026) was aligned with helper packages `0.1.3`. It is superseded by `v0.9.3` and remains available in the repository history.

The earlier `v0.9.1-clean` Word/PDF draft was removed because it included claims that do not match A2SPA behavior, including IETF-style status language, Go/Rust reference implementation language, Ed25519 as a mandatory baseline, RFC 8785 as the signed-byte baseline, and an EEP-generated challenge nonce flow.

Use the Markdown `v0.9.3` draft for current review.
